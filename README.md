# Account Manager – End of Development

After careful consideration, I've decided to retire Account Manager.

With numerous forks now available and other developers actively continuing the work, I feel this is the perfect time for me to step away. It's now time to let others carry the project forward while I focus my time and efforts elsewhere.

AM Lite will no longer receive updates, bug fixes, or support. Existing installations may continue to function, but compatibility with future add-on changes cannot be guaranteed.

I'd like to thank everyone who has supported the project, provided feedback, reported issues, and contributed suggestions over the years.

It's been a rewarding project, but it's time to move on.
